# GitHub Upload Guide

## Recommended Repository Name
`transformative-technology-commercial-banking`

## Recommended Description
Executive commercial-banking simulation for a middle-market technology coverage team: portfolio prioritization, financial statement analysis, credit screening, treasury / FX opportunity mapping, and executive relationship review.

## Upload Order
1. Create the repository.
2. Upload the full folder structure exactly as packaged.
3. Confirm that `README.md` appears on the repository home page.
4. Confirm that the images render correctly.
5. Confirm that the Excel model and PowerPoint deck download correctly.
6. Pin the repository on your GitHub profile.

## Suggested Repository Intro
This project simulates the work of a Commercial Associate supporting a technology-focused middle-market banking team. Using entirely synthetic data, it combines portfolio prioritization, financial statement and cash-flow analysis, downside credit scenarios, treasury and FX opportunity mapping, and an executive relationship review.

## What Not to Claim
Do not say:
- “Bank of America credit model”
- “Bank of America underwriting”
- “Bank of America client”
- “Bank of America approval process”
- “I completed this work for Bank of America”

Use:
- independent simulation;
- commercial-banking case;
- technology coverage portfolio;
- synthetic client;
- preliminary credit screening;
- relationship review.
